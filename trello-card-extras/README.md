# Trello Card Extras

Робить картки Trello читабельними: markdown-таблиці та чеклісти в описі, номери
карток на плитках дошки, значки пріоритету й story points із назви картки.

## Можливості

- **Markdown-таблиці** в описі картки — Trello їх не рендерить, скрипт рендерить;
- **чеклісти** `- [ ]` / `- [x]` як справжні чекбокси, у стилі GitHub;
- **номер картки** на кожній плитці дошки — клік по номеру копіює його,
  іконка `⧉` поруч копіює коротке посилання (картка при цьому не
  відкривається й не тягнеться);
- **пріоритет** `!1`–`!5` із назви — кольоровим чипом із підписом
  (Critical/High/Medium/Low/Lowest), кольори ті самі, що в Strelloids;
- **story points** `(N)` із назви — окремим чипом;
- **копіювання одним кліком** у панелі картки: кнопка `⧉` біля номера копіює
  голий номер (для назв гілок і комітів), а чип із коротким кодом
  (`AdYobF5y`, моноширинний) — повне посилання `https://trello.com/c/<код>`;
- шапки списків в один рядок, довга назва з трикрапкою, повна — у підказці;
- **нижні панелі Trello** — на дошці (Inbox / Planner / Board / Switch boards)
  і у відкритій картці (Power-ups / Automations / Comments) — ховаються
  незалежно, кожна своєю ручкою `▾` / `▴` по центру нижнього краю (видно ту,
  що стосується поточного екрана); вибір кожної запам'ятовується. Місце під
  панель дошки більше не резервується — колонки на всю висоту, а показана
  панель лягає поверх них, тож перемикання нічого не зсуває. Відкрита картка,
  коли панель сховано, розтягується донизу на звільнене місце;
- світла й темна теми: кольори беруться з токенів Atlassian.

## Принципи

**Нічого не руйнуємо в DOM.** Скрипт не видаляє й не переписує вміст опису:
оригінальний вузол ховається, а свій кладеться поруч. Перед тим як Trello
відкриє власний редактор, усе відкочується — інакше редактор підняв би з DOM
наші вставки замість вихідного тексту й зіпсував картку.

**Версія видима.** `@version` у шапці керує автооновленням, `const VERSION` —
тим, що скрипт повідомляє про себе на сторінці:

```js
document.getElementById('card-extras-style')?.dataset.version
```

Версія також у підказці при наведенні на значки в шапці картки. CI падає, якщо
ці два числа розійшлись.

## Встановлення

Відкрити [`trello-card-extras.user.js`](trello-card-extras.user.js) у режимі
Raw — менеджер запропонує встановити. Оновлення приходять самі.

# LostFilm: автовибір найкращої роздачі

На сторінці вибору роздачі скрипт сам знаходить посилання найвищої доступної
якості (1080p → 720p → перше-ліпше), переходить за ним і закриває вкладку,
якщо її відкрив сайт.

## Навіщо

Сторінка вибору якості — зайвий клік у кожній серії. Скрипт прибирає його.

## Як працює

- чекає на появу списку роздач (сторінка домальовує його скриптом);
- витягає число якості з тексту посилання й бере найбільше — тож поява 2160p
  не вимагатиме правок;
- якщо списку немає, тихо виходить: на інших сторінках сайту нічого не робить;
- закриває вкладку лише коли `window.opener` є, тобто коли її справді відкрив
  сайт. Інакше браузер усе одно заборонить, а скрипт не смітить в консоль.

## Встановлення

Tampermonkey → Створити скрипт → вставити вміст `.user.js`.
Або відкрити raw-посилання — менеджер запропонує встановити сам.

## Історія

Перша версія — 21.04.2020, на jQuery. Працювала пʼять років і зламалась, коли
сайт перестав віддавати `$`: у шапці стояла директива `// @3require2` — тобто
`@require` зіпсовано так, що менеджер її не бачив і jQuery не підвантажував.
Скрипт мовчки покладався на бібліотеку самої сторінки.

Оригінал не лежить у робочій теці — у HEAD має бути лише актуальний код. Він
збережений в історії: `git show c4b7d7d` або
[переглянути на GitHub](https://github.com/alex-petr/userscripts/commit/c4b7d7d).

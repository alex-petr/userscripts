# legacy

Історичні версії «як були», без правок. Лежать тут заради історії, не для
встановлення.

- `2020-04-21-jquery.user.js` — перша версія, на jQuery. Працювала пʼять років
  і зламалась, коли сайт перестав віддавати `$`: у шапці стоїть
  `// @3require2 https://code.jquery.com/...` — директиву зіпсовано так, що
  менеджер її не бачить, тож jQuery ніхто не підвантажував. Скрипт покладався
  на бібліотеку самої сторінки.

CI перевіряє ці файли лише на синтаксис: вимагати від них сучасної шапки
означало б переписати те, заради чого їх збережено.
